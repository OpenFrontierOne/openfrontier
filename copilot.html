OFO platform companion

Learn, build, publish, and connect across OFO.

OFO Copilot is the planned browser extension for Open Frontier One. It helps users understand the current store, create crash courses, choose next steps, and find relevant communities without monitoring the wider browser.

Read the product spec View extension scaffold
Scope

Active only on OFO-owned platforms.

The extension is designed as an OFO companion, not a general browser monitor. It should run with privileged context only on domains and store properties operated by Open Frontier One.

Crash courses

Turn a broad topic into a tailored learning path with calibration, glossary, exercises, simulations, and checkpoints.

Contextual coaching

Explain the current store, tool, page, result, or form and suggest the next useful action.

Community matching

Recommend relevant communities, peers, mentors, contributors, reviewers, and professionals with explicit user consent.

Goal navigation

Convert outcomes like “build an AI app” or “publish a website” into steps across the right OFO stores.

Personal memory

Remember user goals, skill level, preferences, and projects in a visible, editable, deletable profile.

Publishing review

Check metadata, broken links, accessibility basics, copy quality, and store-specific requirements before launch.

MVP

Start with a side panel and page context.

The first build should support OFO-only host permissions, current-page context detection, local goals, crash-course prompts, explain-this-page prompts, and community recommendation placeholders. Account sync and deeper matching can come after the extension boundary is proven.
