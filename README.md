# Open Frontier One

Public umbrella website for Open Frontier One.

This repo contains the static site deployed to `openfrontier.one`.

The individual store repos are not part of this repository.

## OFO Copilot

The `extension/` directory contains the first Manifest V3 scaffold for the OFO Copilot browser extension. It is scoped to OFO-owned platforms and stores and is intended to help users learn, build, publish, and connect across the ecosystem.
